## Exact post text

There are over 4 million Shopify stores. 

Less than 1% will ever make it past 7 figures in revenue.

The ones that do, use these 5 fundamental Klayvio flows: 

1) Welcome Series

- The best performing first email
- An absolute MUST
- If you don’t have this, stop reading right now and go set it up!

2) Product (or Browse) Abandonment

- The most overlooked of all the flows
- Performs surprisingly well
- You should also set up SMS product abandonment

3) Category Abandonment

- Not all stores have category
- Still a great flow to set up

4) Cart Abandonment

- The most timely, personalized, relevant flow that exists (Amazon made it ubiquitous)
- Klaviyo calls their “checkout abandonment” flow “cart abandonment” … 
- Make sure you have “add to cart” abandonment set up

5) Checkout Abandonment

- Klaviyo requires you to create this when you open an account
- Don’t confuse it with “cart abandonment” 
- Highly effective with little need for customization

Set these flows up, and you’ll be on your way to the top 1%.
