## Exact post text

Retention.com was responsible for 5% of Dr. Squatch’s TOTAL REVENUE for the holiday season in 2022. We generated more than $1m for them in October of last year alone.

It was all from this 6-part email strategy we set up 90 days before Black Friday:👇

Step 1: Install Retention Scripts (Day 1)

- Install Grow Pixel
- Install Reclaim product, cart, and checkout abandonment pixels
- Instal suppression scripts on email signup forms and checkout
- Install revenue tracking script

Step 2: Integration with Klaviyo (Day 1)

- Set up our OAuth integration
- We hash subscribers currently in Klaviyo account
- Import hashed list as a suppression list

Step 3: Set up Klaviyo Flows (Day 1-5)

- Create new flows for cart, product, and checkout abandonment
- If product flow doesn’t exist, create two versions of it - Klaviyo version and Retention version
- Limited installation to lower-in-the-funnel pages for testing period

Step 4: GO LIVE (Day 7)

- Brand signs off on flows
- Our CS team flips on all of the scripts
- The leaky funnel starts getting clogged

Step 5: 15-Day Deliverability Audit (Day 15):

- Dr. Squatch told us that Klaviyo helped them make sure there was no deliverability issues
- Opens and click-throughs were high, unsubs and spam complaints were low
- Everything performed as well as their existing flows

Step 6: Black Friday Period Performance Evaluation (Day 90)

- Measured performance of our flows vs. all other flows
- Our flows were the highest performing flows for the period
- We generated over 5% of total revenue for the holiday period

And that’s that.
