## Exact post text

Retention.com has driven over $350M in Klaviyo revenue for Shopify stores this year (up from $150M last year).

Here is the 8-step process we use to clog leaky funnels for DTC brands and make them traffic re-capturing machines in just 60 days:

Step 1: Audit Klaviyo Account (Day 1)

- See how many of the 5 Fundamental Flows the brand has set up
- Observe email newsletter size and send cadence
- Evaluate SMS flows

Step 2: Install Retention Scripts (Day 1)

- Install Grow Pixel
- Install Reclaim product, cart, and checkout abandonment pixels
- Instal suppression scripts on email signup forms and checkout 
- Install revenue tracking script

Step 3: Integration with Klaviyo (Day 1)

- Set up our OAuth integration
- We hash subscribers currently in Klaviyo account
- Import hashed list as a suppression list

Step 4: Set up Klaviyo Flows (Day 1-5)

- Create new flows for cart, product, and checkout abandonment
- If product flow doesn’t exist, create two versions of it - Klaviyo version and Retention version
- Set up “Bruce Bolt” implementation for Grow

Step 5: GO LIVE (Day 7)

- Brand signs off on flows
- Our CS team flips on all of the scripts
- The leaky funnel starts getting clogged

Step 6: 15-Day Checkup (Day 15):

- Make sure all of the scripts are firing appropriately
- Check that all of the flows are working properly and showing ROAS
- Make sure email list rules are set up properly, and unengaged users are being removed quickly

Step 7: 30-Day Checkup & Optimization (Day 30):

- Make sure ROAS is on track to exceed expectations
- Suggest tips and tricks to improve flow performance
- High ROAS = everything is great. Low ROAS = creative and flow optimization

Step 8: Analyze Performance (Day 60):

- Look at ROAS across our two products (almost always stellar)
- Predict 12mo CLTV for Grow and Reclaim given time of year and seasonality of business
- The trial period is over, and the Brand becomes a lifelong customer

And that’s that.
