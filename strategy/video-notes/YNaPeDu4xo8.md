- Product identification is initially qualified as up to 35%, then stated as 35% in later scripts. Preserve the original qualification when using it as a capability claim.

- The transcript calls the email-provider waterfall verification, but describes using a second source only if the first lacks an address; it does not establish independent validation of every result.

- The source does not isolate ABM's causal contribution to the $13 million ARR milestone or substantiate the title's implied causal certainty.
